# Majestic Gems

A Godot 4.6.3 portrait gem-launching merge game.

## Current milestone

`supplied-art-purple-ui-cleanup-v1` integrates the supplied 10 backgrounds, 10 tables, and 20 precisely cropped gems; recalibrates the shared table/physics geometry; removes player-facing gem names; applies the dark-amethyst reference theme without changing UI layout; and organizes active code/assets by responsibility.

See `reports/SUPPLIED_ART_PURPLE_UI_CODEBASE_CLEANUP_V1_REPORT.md`, `CURRENT_STATE.md`, `ASSET_INVENTORY.md`, and `BUILD_MANIFEST.md`.

## Project layout

- `assets/backgrounds`, `assets/tables`, `assets/gems`, `assets/ui`, `assets/sound`, `assets/logo`, `assets/buttons`: preserved source inputs.
- `assets/runtime`: optimized, package-ready derivatives used by the game. This boundary prevents oversized originals from being shipped and is regenerated by `scripts/dev/prepare_supplied_art_refresh.gd` for the current scene/gem set.
- `scripts/core`: configuration, catalog, level data, pieces, contact data, formatting.
- `scripts/gameplay`: simulation, merge resolution, and controller orchestration.
- `scripts/presentation`: gem sprites, effects, coins, and target reward visuals.
- `scripts/ui`: HUD, Home, and Result UI.
- `scripts/services`: ads, audio, haptics, settings, and persistence.
- `scripts/dev`: reproducible development-only asset preparation.
- `tests`: regression and capture scripts.
- `reports`: milestone reports and visual evidence.
