# Reference Gameplay Coin Parity Evidence

These four PNGs are deterministic renders from the production `Game.tscn` using Godot 4.6.3 Compatibility/ANGLE at 720 × 1600. They show the ready aim guide, a confirmed major-merge coin burst, staggered coin travel into the HUD, and the exact settled run-coin total.

The coin artwork and sounds are original procedural work. No frames, art, or audio from the supplied reference recording are included in the project.
